# FlashLearn – Backend
Studentisches Projekt im Modul Webtechnologien an der HTW Berlin.

## Worum geht's?
FlashLearn ist eine Lernkarten- und Quiz-App als Website. Nutzer:innen können digitale Karteikarten für verschiedene Fächer erstellen, üben, in Schwierigkeitsgrade einteilen und ihren Lernfortschritt verwalten.

## Technik 
**- Backend:**  Java 25, Spring Boot, Gradle als Build-Tool
**- Frontend:** Vue.js, Node.js, Vite
**- Datenbank:** PostgreSQL

## Starten 
./gradlew bootRun
